# DroidService Pro 0.2.6

Android 8.0 и новее. Переключатель RU/EN находится в верхней части экрана и сохраняет язык.

## Сборка

Откройте корень проекта в Android Studio с JDK 17 и Android SDK 35 или выполните `gradle --no-daemon assembleDebug` с Gradle 8.9. Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

В GitHub запустите **Actions → DroidService Pro APK → Run workflow**. Сборка публикует артефакт **DroidServicePro**. Для установки поверх 0.1.0 APK необходимо подписать тем же ключом, которым подписана установленная версия.

## Проверка USB на Galaxy S26 и Galaxy S23 Ultra

1. На Galaxy S23 Ultra (SM-S918B/DS) включите отладку по USB и разблокируйте экран.
2. Соедините телефоны кабелем с передачей данных. Galaxy S26 должен работать в роли USB-хоста.
3. На S26 откройте **Телефон**, обновите список USB и нажмите **Читать через ADB** напротив S23 Ultra. При первом запросе разрешите USB-доступ приложению на S26.
4. На S23 Ultra подтвердите системный RSA-запрос. Приложение читает свойства Android командой `getprop` и закрывает соединение. Закрытый ключ хранится в Android Keystore S26.
5. Сверьте модель, сборку и значения CSC с разделом **Версия ПО поставщика услуг** на S23 Ultra. Для тестового телефона в предыдущем разговоре указаны XXV и OXM. Значение, которое прошивка не раскрывает, отображается как «Не определено».
6. В разделе **CSC** найдите и выберите EUX. Убедитесь, что интерфейс показывает статус совместимости, а также что язык и переносы строк читаются в обоих режимах.
7. Повторите диагностику после отклонения USB-разрешения или RSA-запроса, а также после отсоединения кабеля. Проверьте сообщение на экране и в журнале.

Приложение показывает активный CSC по доступному пути OMC, отдельно выводит код продаж и пробует определить пакет Multi-CSC по свойствам прошивки. Заводской CSC по этим данным не устанавливается. Справочник содержит 66 кодов. Совместимость перехода XXV → EUX на этой сборке остаётся неподтверждённой. В приложении доступны диагностика и выбор кода для сверки.

## Wi‑Fi ADB

Для штатного сопряжения подключите S23 Ultra и компьютер с Android SDK Platform-Tools к одной сети. На телефоне откройте **Для разработчиков → Беспроводная отладка → Сопряжение устройства с помощью кода**. На компьютере выполните `adb pair IP:порт_сопряжения` и введите код в ответ на запрос. При необходимости выполните `adb connect IP:порт_отладки`, используя адрес и порт с главного экрана беспроводной отладки, затем проверьте `adb devices`.

DroidService Pro показывает эту инструкцию. Диагностика внутри приложения в 0.2.6 работает по USB.

## Сверка активного CSC

После чтения телефона нажмите **Показать свойства CSC** на вкладке **Телефон**. Рядом с определённым кодом указано его исходное свойство. В диагностике отдельно видны пустые свойства и свойства, которых нет в ответе USB ADB.

Для SM-S918B на сборке S918BXXUAGZIF контрольное значение из настроек Samsung — `SAOMC_SM-S918B_OXM_XXV_17_0006`. При недоступном или нераспознанном пути активного OMC активный CSC остаётся неопределённым. Код продаж и сетевые пути OMC доступны для сверки отдельно. Версия 0.2.6 распознаёт путь /optics/configs/carriers/single/XXV/conf, полученный от S23 Ultra через USB ADB.
## Проверка USB-модема

На S26 откройте **Телефон** и нажмите **Проверить USB-модем** для S23 Ultra. Приложение показывает USB-интерфейсы и проверяет канал обычной AT-командой `AT`.

## Смена активного CSC

1. Подключите S23 Ultra к S26, включите USB debugging и подтвердите системный RSA-запрос.
2. Нажмите **Читать через ADB**. Приложение попробует получить список CSC из файлов прошивки через ADB shell. Вкладка CSC показывает, какие коды найдены; смена доступна только для кода из списка устройства.
3. Выберите EUX (если он присутствует в списке) и нажмите **Сменить CSC**. Внимательно прочитайте предупреждение и подтвердите операцию. Приложение отправляет Samsung AT-команды через USB CDC, затем запрашивает перезагрузку.
4. После запуска телефона снова прочитайте данные по ADB и сравните с **Настройки → Сведения о ПО → Версия ПО поставщика услуг**.

Метод основан на опубликованной независимой реализации Samsung Protected AT. Он не является официально поддерживаемой Samsung процедурой и не проверен на каждой модели или версии прошивки. Перед операцией сделайте резервную копию; возможны сброс настроек, ограничения сети и изменение поведения OTA. Изменяется активный CSC, но заводской CSC может остаться прежним. Используйте только код из считанного списка прошивки.
