# DroidService Pro — Android starter project

**Версия:** 0.1.0  
**Платформа:** Android 8.0+ (API 26+)  
**Языки интерфейса:** русский + английский  
**Тема:** тёмная

## Открытие проекта
1. Установите Android Studio.
2. Распакуйте архив.
3. В Android Studio выберите **Open** и укажите папку `DroidServicePro`.
4. Дождитесь Gradle Sync.
5. Подключите Android-телефон или выберите эмулятор.
6. Нажмите **Run**.

Для сборки APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Что уже есть
- Тёмный двуязычный интерфейс.
- Главная панель.
- Информация о телефоне, на котором запущено приложение.
- Обнаружение USB-периферии через Android USB Host API (ручное сканирование).
- Инструкция по штатному сопряжению Wireless Debugging.
- Справочник CSC и выбор целевого кода.
- Предупреждения о совместимости и рисках.
- Базовый журнал сессии.

## Ограничения прототипа
Это исходный каркас, а не готовая замена Windows SamFw Tool. Он **не** выполняет смену CSC, прошивку, ADB-команды, FRP bypass или удаление аккаунтов. Android не предоставляет обычному приложению универсального доступа к сервисным функциям Samsung. Доступность чтения CSC и сервисных операций зависит от модели, прошивки, региона и авторизованных интерфейсов.

USB Host здесь обнаруживает подключённую USB-периферию. Для полноценной работы с другим телефоном могут потребоваться поддержка USB OTG, кабель/переходник, разрешение пользователя и совместимый протокол. Сам факт USB-обнаружения не означает, что устройство доступно по ADB.
